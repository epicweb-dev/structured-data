# Array Types

<EpicVideo url="https://www.epicweb.dev/tutorials/structured-data/2-arrays/array-types" />

👨‍💼 Let's work with arrays of objects—a very common pattern in real
applications.

```ts
type User = { name: string; age: number }
const users: Array<User> = [
	{ name: 'Alice', age: 30 },
	{ name: 'Bob', age: 25 },
]
```

🐨 Open <InlineFile file="index.ts" /> and:

1. Create a `Product` type alias with `name` (string), `price` (number), and
   `inStock` (boolean)
2. Create a `products` array typed as `Array<Product>` starting with these three
   objects (in this order):
   - `{ name: 'Laptop', price: 999.99, inStock: true }`
   - `{ name: 'Mouse', price: 29.99, inStock: true }`
   - `{ name: 'Keyboard', price: 79.99, inStock: false }`
3. `push` a fourth product:
   `{ name: 'Monitor', price: 299.99, inStock: true }`
4. Log the name of the first product (`products[0].name` should be `'Laptop'`)
5. Calculate `totalValue` by summing every product's `price` with a loop
   (expected total: `1409.96`)
6. Export `products` and `totalValue`

💰 Arrays have methods for adding elements.

💰 You can iterate through arrays to calculate totals.

<callout-info>
	There's a more concise way to sum arrays with `reduce`, and we'll cover that
	in the Array Methods exercise later.
</callout-info>
