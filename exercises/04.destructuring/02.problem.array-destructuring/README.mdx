# Array Destructuring

<EpicVideo url="https://www.epicweb.dev/tutorials/structured-data/4-destructuring/array-destructuring" />

👨‍💼 Array destructuring extracts elements by position. It's especially useful for
working with function return values and APIs that return arrays.

```ts
const colors = ['red', 'green', 'blue']
const [first, second, third] = colors
// first = 'red', second = 'green', third = 'blue'
```

## Skipping Elements

Use empty slots to skip elements you don't need:

```ts
const [, , third] = colors // third = 'blue'
```

## Rest Pattern

Collect remaining elements into a new array:

```ts
const [head, ...rest] = [1, 2, 3, 4, 5]
// head = 1, rest = [2, 3, 4, 5]
```

<callout-info>
	The spread/rest syntax was covered in Exercise 3. The `...rest` pattern here
	collects remaining array elements into a new array.
</callout-info>

## Swapping Variables

Destructuring enables elegant swaps:

```ts
let a = 1
let b = 2
;[a, b] = [b, a] // a = 2, b = 1
```
