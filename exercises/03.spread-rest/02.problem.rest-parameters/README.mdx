# Rest Parameters

<EpicVideo url="https://www.epicweb.dev/tutorials/structured-data/3-spread-and-rest/rest-parameters" />

👨‍💼 Rest parameters let functions accept any number of arguments, collected into
an array. This is the opposite of spread—instead of expanding, we're collecting.

```ts
function joinWords(...words: Array<string>): string {
	return words.join(' ')
}

joinWords('hello', 'world') // "hello world"
```

<callout-info>
	If you need to walk every rest argument before we cover `.reduce()` in
	Exercise 5, a simple `for...of` loop works well:

```ts
function longestWord(...words: Array<string>): number {
	let maxLength = 0
	for (const word of words) {
		if (word.length > maxLength) {
			maxLength = word.length
		}
	}
	return maxLength
}
```

</callout-info>

## Rest vs Spread

The `...` syntax means different things in different contexts:

```ts
// SPREAD - expanding into individual elements
const arr = [1, 2, 3]
console.log(...arr) // 1 2 3 (expanded)

// REST - collecting into an array
function fn(...args: Array<number>) {
	// args is an array of all passed numbers
}
```

## Combining with Regular Parameters

Rest must be the last parameter:

```ts
function greetAll(greeting: string, ...names: Array<string>): string {
	return names.map((name) => `${greeting}, ${name}!`).join(' ')
}

greetAll('Hello', 'Alice', 'Bob', 'Charlie')
// "Hello, Alice! Hello, Bob! Hello, Charlie!"
```
