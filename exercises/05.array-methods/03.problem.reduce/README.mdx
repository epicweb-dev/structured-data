# Reduce

<EpicVideo url="https://www.epicweb.dev/tutorials/structured-data/5-array-methods/reduce" />

👨‍💼 The `reduce` method accumulates an array into a single value. It's the most
powerful (and sometimes confusing) array method—and a cornerstone of functional
programming.

```ts
const numbers = [1, 2, 3, 4]
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 10
```

Parameters:

- **accumulator** (`acc`) - The running total
- **current** (`n`) - The current element
- **initial value** (`0`) - Starting point

💰 `reduce` combines all items into one accumulated result.

💰 When counting with an object accumulator, you can either update a single
object or return a new object each step — choose the approach you find clearer.
