# Unique Values with Set

<EpicVideo url="https://www.epicweb.dev/tutorials/structured-data/7-maps-and-sets/sets" />

👨‍💼 We collect tags from multiple sources and need to remove duplicates.

🐨 Open <InlineFile file="index.ts" /> and use the provided `tags` fixture:

1. Create `uniqueTags` as a `Set` from `tags` (size should be `4`)
2. Create `hasTypeScript` by checking whether the set has `'typescript'`
   (expected `true`)
3. Create `tagList` by converting the set back into an array — preserve
   insertion order:
   `['typescript', 'data', 'arrays', 'objects']`
4. Export `uniqueTags`, `hasTypeScript`, and `tagList`
