# Object Literals

<EpicVideo url="https://www.epicweb.dev/tutorials/structured-data/1-objects/object-literals" />

👨‍💼 We're building a user management system. We need to represent user data as
objects with proper types.

🐨 Open <InlineFile file="index.ts" /> and:

1. Create a `user` object with these exact properties:
   - `name`: `'Alice'`
   - `age`: `30`
   - `email`: `'alice@example.com'`
2. Create a second object named `admin` with the same property names and these
   exact values:
   - `name`: `'Bob'`
   - `age`: `35`
   - `email`: `'bob@example.com'`
3. Export both objects: `export { user, admin }`

You'll know you're done when `user` and `admin` are exported with those exact
property values.

🦺 Object type syntax (we'll name these types in a later step):

```ts
const obj: { prop1: Type1; prop2: Type2 } = {
	prop1: value1,
	prop2: value2,
}
```
