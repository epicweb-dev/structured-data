# Dynamic Object Keys

<EpicVideo url="https://www.epicweb.dev/tutorials/structured-data/1-objects/dynamic-keys" />

👨‍💼 We need to model error pages where the property name isn't a valid
identifier (like `status-404`).

When the property name is stored in a variable, you can use a computed property
name in an object literal:

```ts
const key = 'status-404'
const errorPages = {
	[key]: '/not-found',
}
```

🐨 Open <InlineFile file="index.ts" /> and:

1. Create an `errorPages` object literal that uses the provided key variables
   (`notFoundKey`, `serverErrorKey`) as computed property names
2. Assign the matching path variables (`notFoundPath`, `serverErrorPath`) as
   values — do not hard-code different key strings or paths
3. Export `errorPages`

When finished, `errorPages` should behave like:

- `errorPages['404-status'] === '/not-found'`
- `errorPages['500-status'] === '/server-error'`
